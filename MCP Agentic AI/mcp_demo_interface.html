🧠 MCP-Agentic-AI — Input / Output Interface

Live runner for the scripts in this repo. Each example connects an LLM (Ollama / Groq) to a real MCP server through web_app.py. Pick a script, edit its input query, press ▶ Run agent, and watch the live output stream — tool calls, observations and the final answer appear as they happen. Scripts not wired into the backend show a simulated walkthrough instead.
